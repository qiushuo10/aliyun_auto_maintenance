# **主页面描述**
本系统使用的是客户端程序

## **1\. 三栏式页面功能区详述**

根据高保真 UI 渲染模型，界面采用深色极客暗黑主题（\#121215），划分为三个独立的物理控制列：

### **2.1 第一列：极左侧空间隔离与会话管理舱 (Local Sandbox & Sessions)**

本列在物理层面隔离用户的物理资源路径、逻辑配置主体以及多沙箱会话之间的短期记忆。

#### **2.1.1 📁 本地工作空间选择器 (Workspace Selector)**

* **产品定义**：管理并挂载用户本地磁盘上的具体运维物理文件夹（例如 /ops/car-aftermarket）。  
* **核心交互**：  
  * **空间切换**：下拉菜单支持在多个注册的工作空间中快速横向切换。  
  * **挂载新工作空间**：点击“➕ 挂载新工作空间...”可拉起桌面系统级文件夹选择器，支持增量虚拟挂载新的物理路径、选择的时候使用系统的文件夹选择来做。  

#### **2.1.2 👤 执行绑定主体选择器 (Profile Selector & ⚙️ 属性面板)**

* **产品定义**：逻辑层面的阿里云账号凭证、多租户与环境边界。  
* **⚙️ 属性面板（三字段安全落盘）**：点击唤起配置 Modal，提供专属于该 Profile 的阿里云环境配置：  
  1. **AccessKey ID (Key)**：明文 AK 录入。  
  2. **AccessKey Secret (秘钥)**：密码掩码（Password Mask）脱敏录入，防止投屏暴露。  
  3. **云效企业/项目 ID (RDC ID)**：用于流水线构建、代码托管等特定企业云级产品，保证企业账号属性物理存储隔离。  
  4. **专属代理长效记忆偏好（prefs.md）**：手动剪枝和优化 Agent 在此 Profile。

#### **2.1.3 💬 独立会话沙箱列表 (+ 新建对话)**

* **产品定义**：将对话解耦成独立的短期上下文和记忆隔离容器（Req 1 & Req 2）。  
* **核心交互**：  
  * **新建对话**：点击拉起命名引导，强制指定或自动继承当前运行的执行主体（Profile）。  
  * **运行主体勋章**：每个会话卡片上清晰挂载专属的主体标识（如 🚗 car-aftermarket）和会话安全签盾（🔒核签 或 ⚡免签）。  
  * **物理短期记忆隔离**：横向切换会话时，主聊天区域流、中栏装载的文档指针状态瞬间初始化隔离，防止不同项目云环境之间的数据交叉感染。

#### **2.1.4 底部常驻微入口 (Static Widget Bar)**

* **⏰ 周期定时任务控制台**：直观展示本地 app.db 中有多少个处于活跃监视（Active）的 Daemon 周期任务，可一键唤起主任务控制台。  
* **📊 统一安全网关审计日志**：一键调阅 app.db \-\> tool\_invocations 本地拦截大账本，实现每次调用的合规审计和物理溯源。

### **2.2 第二列：中栏 — 动态短期上下文常驻指针 (Short-term Context Dashboard)**

本列展示当前激活会话（Active Session）在当前轮次的短期上下文中所“吃”进的物理事实、提取的 API 信息和推荐技能的大纲指针。

#### **2.2.1 📄 已装载业务文档指针 (Pointers Only)**

* **产品定义**：指明 Agent 在解决当前问题时，加载了哪些本地业务 Markdown（如 短信/签名.md）。  
* **设计规范**：**严格禁止正文堆砌**。只展现：文件名、物理路径大小、以及最后的 Chokidar 增量修改同步时间。  
核心是用来表达使用了哪些知识

#### **2.2.2 ⚙️ 关联提取接口事实 (catalog.db FTS5)**

* **产品定义**：显示通过本地 FTS5 引擎从只读事实库 catalog.db 精准匹配出的 OpenAPI 元数据。  
* **展现内容**：产品码（如 dysmsapi，自动自纠并屏蔽 RAM 码 dysms 的易混干扰）、Action 接口名、网关对该接口定义的 danger 评级（safe / write / dangerous）以及必填项断言约束。

#### **2.2.3 🧠 \[主体专属\] 代理偏好记忆 (Collapsed by default \- Req 4\)**

* **产品定义**：展示当前 Profile 专属的长效交互与运维偏好约束（源自 .agent-memory/prefs.md）。  
* **设计规范**：**默认采取 collapsed (收起) 抽屉状态**，保证初始界面清爽度。点击展开后，以精简的 bullet points 展示 Agent 的潜规则偏好底盘，允许随时点击编辑和裁剪。

#### **2.2.4 🌐 全局推荐技能 (Global Playbooks)**

* **产品定义**：出厂预装的高频常驻运维 SOP（如 *一键部署 SSL 安全证书*），支持点击一键载入至主输入框，提供高效的快捷指令引流。

### **2.3 第三列：主对话与安全网关执行区 (Action & Gatekeeping Panel)**

右侧是智能交互流和物理安全的终极闭环区。

#### **2.3.1 ✏️ 灵动场景会话控制头部 (Header with editable title)**

* **可重命名场景标题**：支持双击或直接点击修改场景标题（如将默认新会话名字自主修改为 **“短信服务配置会话”**），回车即落盘更新会话数据库。  
* **执行主体勋章**：醒目挂载当前会话绑定的物理主体（如 🚗 CAR-AFTERMARKET），便于运维人员在执行高危指令前进行二次确认。  
* **会话信任等级选择器**：本系统的核心安全控制器。  
  1. **🔒 严控核签模式 (默认)**：系统网关触发 write 级别接口时锁死调用，强制在右侧流中渲染“人机审查卡”，用户手动签署后方可本地发包。  
  2. **⚡ 完全信任免签 (Auto-pilot)**：会话进入自动化托管。safe/write 操作仍必须先经过网关自纠偏、参数清洗和审计记录后才可静默发包；dangerous 操作永远不能免签，必须回到人工确认卡。

#### **2.3.2 🔄 统一网关层无损自纠错处理链 (FAIL-CLOSED Gate Accordion)**

* **产品定义**：以高度透明、可折叠的形式，展示网关内部自纠偏和错误事实回灌的流程（文档 §9）。  
* **展示逻辑**：默认收拢，防止技术细节干扰直觉。点击展开可查看：*在 Loop 1 错填接口 AddSmsTemplate 失败，网关 fail-closed 拦截并向 loop 回灌自纠偏真相，Loop 2 自动无损校正发包端点为 CreateSmsTemplate 通关* 的细节，展示系统自我排障逻辑。

#### **2.3.3 ⚠️ 高危写操作人工最终核签审查卡 (Pre-Flight Card)**

* **产品定义**：严控核签模式下的第三层物理防御壁垒。  
* **数据可溯源性 (Data Provenance)**：即将发包的 API 参数明细表中，每一个关键参数后均高亮标注其在本地工作空间的物理出处（如 RegionId 来自 📄 环境/region.md；SignName 来自 📄 短信/签名.md），彻底消灭 AI 自发编造参数的可能。  
* **双向控制按钮**：  
  * **拒绝并中止**：触发安全熔断，彻底撤销本次工具调用，并在审计表记录 REJECTED-用户人工阻断。  
  * **确认授权执行**：启动 OpenApiClient，使用本地解密的 Key 和 Secret 组装请求并发出发包，返回 200 返回码与 RequestId。

#### **2.3.4 ⌨️ 多模态运维输入控制栏**

* 输入框支持使用 @ 快捷键，强行唤醒本地工作空间的特定文件绑定上下文；  
* 支持 Enter 快捷键直接发射运维意图，Shift \+ Enter 换行。  
* 底部常驻 Chokidar Live 状态与本地元数据库 catalog.db 的索引就绪状态，确保环境健康度。

## **3\. 定时任务双窗格控制台微模块 (Scheduled Tasks Console)**

由于是本地优先桌面应用，定时任务依赖 Electron 常驻后台的 Daemon 进程轮询：

\+-------------------------------------------------------------------------+  
|                  本地常驻周期定时控制台 (scheduled\_tasks)                  |  
\+-------------------------------------------------------------------------+  
| \[TAB 💼 业务运维定时任务\]               |                                |  
| • Task 1: ECS健康巡检 (Running)        | \[右窗格 \- TASK DEEP INSPECTOR\]   |  
| • Task 2: 核心安全组阻断 (Awaiting Sign) | • 任务名称 & Cron 表达式         |  
|                                         | • 物理绑定主体与安全等级          |  
| \[TAB 🤖 软件系统自维护任务\]              | • 常驻后台执行 JS 脚本 (可读)    |  
| • Task 3: 自动提炼历史错误技能 (Running)  | • 近期执行历史 live 日志流       |  
| • Task 4: 专属长效记忆巩固 (Running)    | • 🎮 暂停调度 / ⚡ 立即触发测试     |  
\+-------------------------------------------------------------------------+

### **3.1 业务运维定时任务 (Business Tasks)**

* **产品定义**：针对绑定主体的云资产调度，包括 *ECS 巡检*、*域名 SSL 安全证书巡检*。  
* **高危“首次签署”安全机制 (First-sign Handshake)**：对于 dangerous 评级的定时器（如 *核心安全组入向高危端口阻断*），状态被初始化为“等待初始授权”。用户必须手动点击“测试触发”，在桌面系统弹出的授权窗口中进行“首次运行凭证签署确认”后，Daemon 进程才会允许该任务进入后台定期托管运行，消除了 AI 自发生成危险 Cron 的后门。

### **3.2 软件系统自维护任务 (System Tasks)**

* **产品定义**：本运维 Agent 的清道夫与自愈认知系统，包括：  
  1. **自动提炼历史错误并升格为全局技能**：定时扫描本地 app.db 审计日志中高频因为别名错误（如 dysms 填错）被网关拦截的日志，由后台模型进行规律整编，将其固化并升格成“全局推荐技能（Global Playbooks）”推荐给用户，消灭重复报错，实现 Agent 运维经验的自主繁衍。  
  2. **专属代理长效记忆精简化合并与巩固 (Consolidation)**：每周日零点定期对 .agent-memory/ 进行重组合并，清除冲突偏好，保持上下文决策层高度精准。

### **3.3 深度视察面板 (Task Deep Inspector)**

* 点击任意定时任务卡，右侧视察器将清晰地投射出该任务的 **受限 DSL / action graph** 以及由 DSL 编译出的只读 JS 预览，并展示包含精确时间戳的 **Recent Executions（实时运行历史日志流）**，使每一次后台执行结果都透明、可溯。

## **4\. 统一安全网关拦截审计日志 (Gateway Audit Log)**

* **数据库映射**：本地 app.db \-\> tool\_invocations 拦截大账本。  
* **产品功能**：无论用户处于“严控核签模式”还是“完全信任免签模式”，只要 API 越过网关边界，系统均会按时间逆序强制将：*触发时间、工具方法、网关处理状态（如 REJECTED / SUCCESS）、目标 Endpoint 端点、授权使用 AK ID* 进行本地归档存储，形成 v1 的本地可追溯审计大账本。v1 不包含企业合规导出、签名导出或 hash chain。

# **智能意图决策与信任中枢 (Intelligent Intent Decision & Trust Hub) — 功能描述与设计规范**

本模块是用户与 Agent 进行高频交互的主战场。它通过多模态的信任度管理与动态指令流，实现对云上运维操作的实时确权与执行。

## **1\. 产品定位 (Product Positioning)**

决策中枢是整个运维 Agent 的“方向盘”。它负责解析用户的自然语言指令，结合上下文环境生成可执行的 API 调用序列，并根据安全等级进行实时的决策与反馈。

## **2\. 核心功能点 (Functional Specs)**

### **2.1 会话信任等级切换 (Trust Level Toggle)**

* **严控核签模式 (Nuclear Authorization Mode)**：  
  * 这是系统的安全基石。任何涉及 write 级别的 API 调用，系统均会在此处自动拦截，生成一份详细的“操作审查卡”，要求运维人员人工确认后方可发包。  
* **完全信任免签模式 (Auto-pilot Mode)**：  
  * 适用于低风险的操作场景。在此模式下，Agent 拥有更高的自主权，可直接执行经过网关校验的 safe/write API 指令，极大提升运维效率；dangerous 操作永远不能免签，仍必须进入人工确认。

### **2.2 多模态指令执行流 (Multimodal Action Stream)**

* **意图解析可视化**：当用户输入指令后，中枢会自动将复杂的运维意图拆解为细粒度的步骤，并以卡片形式逐一展现，使用户清晰了解 Agent 的每一步思考过程。  
* **参数出处可溯源 (Data Provenance)**：在每一个 API 操作节点上，系统明确标注参数的来源（例如：RegionId 来源于 📄 环境配置.md），确保运维逻辑的严谨与可控。

### **2.3 动态自纠偏 (Dynamic Self-Correction)**

* **网关拦截与自动回灌**：若指令调用失败，网关会自动捕捉错误原因，并将错误事实“回灌”给 Agent 的上下文，触发 Agent 自主调整参数或寻找替代接口，实现无损的自愈式运维。

## **3\. 设计规范 (UI/UX)**

* **简洁明快的信息层级**：顶部为会话标题与信任等级控制，中部为交互流记录，底部为输入控制。整体风格采用高响应式布局，确保在不同屏幕尺寸下均能精准操作。  
* **视觉语言差异化**：  
  * **操作卡片 (Action Cards)**：清晰的背景区分，高危操作使用警示黄色边框或背景。  
  * **反馈标识**：通过成功、失败、等待审核等状态颜色，实现一目了然的操作确认。  
* **便捷输入**：输入框支持快捷键输入，通过 @ 符号快速引用特定配置文档或历史技能，提升指令输入速度。

## **4\. 交互安全准则**

* **Fail-Closed 闭环逻辑**：任何未能通过安全校验的意图，都会被直接拒绝，并引导用户修改指令。  
* **操作透明化**：所有交互记录均会同步至“审计中心”，确保操作轨迹有据可查。
